# Factory ERP Starter (โรงงานประตูหน้าต่างอลูมิเนียม)

โปรเจกต์นี้เป็นระบบ ERP แบบเริ่มต้นสำหรับโรงงานประกอบประตูหน้าต่างอลูมิเนียม โดยรองรับ workflow ตั้งแต่

- ฐานข้อมูลพนักงาน
- ฐานข้อมูลลูกค้า
- ออกใบเสนอราคา
- คำสั่งผลิต
- งานติดตั้ง
- ส่งมอบงาน

ระบบใช้ SQLite และมี CLI สำหรับเริ่มฐานข้อมูล, ใส่ข้อมูลตัวอย่าง และออกรายงาน Quote → Delivery

## โครงสร้าง
- `app.py` : แกนหลัก ERP + CLI
- `tests/test_app.py` : ทดสอบกระบวนการครบทั้งสายงาน

## การใช้งาน
```bash
python app.py --init
python app.py --demo
python app.py --report
```

## ทดสอบ
```bash
python -m pytest
```
